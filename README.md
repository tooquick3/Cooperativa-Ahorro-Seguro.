# CooperativaAhorroSeguro.
Proyecto académico desarrollado en C# para la cooperativa Ahorro Seguro. Consiste en una aplicación de consola que simula las operaciones de un cajero automático y un sistema de préstamos, aplicando estructuras condicionales, ciclos repetitivos y validación de datos.
